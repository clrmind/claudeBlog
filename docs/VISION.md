# Atlas Vision

**Atlas는 다양한 도메인의 지식을 수집하고, 구조화하고, 검색하고, 추천하며, 필요한 순간에만 AI를 활용하는 Knowledge-first 플랫폼이다.**

## Mission
Atlas의 목표는 정보의 양을 늘리는 것이 아니라, 신뢰할 수 있는 지식을 축적하고 이를 실제 의사결정에 활용할 수 있게 만드는 것이다.

## Core Philosophy
- Knowledge First. AI Second.
- Search Before AI.
- Rule Before LLM.
- AI Is Replaceable.
- Failure Must Not Stop Atlas.

## First Product
정부지원사업은 Atlas의 첫 번째 도메인이다.

```text
List Collector
→ Detail Collector
→ Attachment Collector
→ Normalizer
→ Knowledge Store
→ Tagger
→ Search
→ Recommendation
→ Assistant
→ Publisher
```

## North Star Metric
**AI 없이도 정확하게 해결 가능한 업무 비율**
